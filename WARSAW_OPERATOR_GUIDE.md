# Отложенная рассылка: инструкция для оператора в Варшаве

## Перед началом

На сервере в `.env` должен быть указан часовой пояс Варшавы:

```dotenv
SCHEDULE_TIMEZONE=Europe/Warsaw
```

Бот будет принимать время по Варшаве. Переход между зимним временем CET и летним временем CEST учитывается автоматически.

## Как запланировать рассылку

1. Откройте личный чат с ботом.
2. Для удобного выбора нескольких групп кнопками отправьте:

   ```text
   /broadcast_select
   ```

3. Бот покажет название и alias каждого направления. Нажмите на нужные строки — выбранные направления будут отмечены `✅`.
4. Если список занимает несколько страниц, используйте `Previous` и `Next`.
5. Проверьте число выбранных направлений на кнопке `Continue`, затем нажмите её.

Для отправки во все активные группы без выбора используйте:

   ```text
   /broadcast
   ```

Если aliases уже известны, выбранные направления можно указать в команде:

   ```text
   /broadcast validator-ru gw2-support
   ```

Для тихой рассылки с кнопочным выбором используйте:

   ```text
   /broadcast_select_silent
   ```

Для тихой рассылки во все направления используйте:

   ```text
   /broadcast_silent
   ```

6. Отправьте боту одно полностью готовое сообщение: текст, фотографию, видео или документ.
7. Проверьте предпросмотр, ссылки, вложение и количество групп.
8. Нажмите `Schedule`.
9. Отправьте дату и время в формате:

   ```text
   YYYY-MM-DD HH:MM
   ```

   Например:

   ```text
   2026-08-20 14:30
   ```

10. Убедитесь, что бот ответил подтверждением с номером рассылки, временем и пометкой `Europe/Warsaw`.

## Как проверить расписание

Отправьте:

```text
/history
```

У запланированной рассылки будет статус `scheduled` и указанное время отправки.

## Как отменить рассылку

До начала отправки нажмите `Cancel scheduled broadcast` под подтверждением либо используйте номер рассылки:

```text
/cancel ID
```

Например:

```text
/cancel 42
```

После начала отправки отмена уже недоступна.

## Важные замечания

- Указывайте будущее время именно по Варшаве.
- Бот отклонит несуществующее или неоднозначное локальное время в ночь перехода CET/CEST. Выберите другое время.
- Обычный перезапуск бота не удаляет запланированные рассылки: они хранятся в SQLite.
- Фактический старт может запоздать до `POLL_TIMEOUT_SECONDS` (по умолчанию до 30 секунд), а при недоступности Telegram API — до восстановления связи.
- Если бот аварийно остановился уже во время отправки, такая кампания не запускается повторно автоматически, чтобы не создавать дубли.
- Перед подтверждением ещё раз проверьте получателей, дату, время, часовой пояс, ссылки и вложение.
